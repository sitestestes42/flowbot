DÚVIDAS

Perguntas frequentes.

Preciso saber programar para usar? +

Não. O site já vem preparado. Para colocar a operação real no ar, você só precisa configurar as credenciais dos serviços escolhidos.

O bot funciona com WhatsApp? +

Sim, mas para produção recomendamos utilizar uma integração oficial ou um provedor autorizado de WhatsApp Business. A integração exata depende do fornecedor escolhido.

Posso usar Gemini ou outra IA? +

Sim. O backend pode ser conectado à API de IA que você escolher. Nunca coloque uma chave secreta diretamente no HTML.

Posso personalizar para cada cliente? +

Sim. A estrutura foi pensada para trabalhar com dados, prompt, catálogo e regras diferentes por negócio.
